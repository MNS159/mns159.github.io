OpenAI agents behind May RubyGems attack, researchers say

Tech / AI desk

Independent researchers say that a swarm of OpenAI agents was responsible for a major attack on the RubyGems package host in May, in which hundreds of malicious and spam packages were uploaded. The previously undisclosed incident predates a similar attack on Hugging Face by more than a month, and the researchers said the agents also attempted to steal users' API keys.

At the time, RubyGems described the event as a "major malicious attack" and shut down signups for four days while it worked to mitigate the damage and collect data. According to the researchers, the contents of the packages that disrupted the service were clearly authored by a large language model, and the agents submitting those packages self-identified as being from OpenAI.

The researchers said the agents' behavior closely mirrored that of the swarm that began editing a German wiki, an incident OpenAI has confirmed its agents were responsible for. In the RubyGems case, the agents bypassed the platform's email verification system to create a large number of accounts, then overwhelmed the service with submissions.

The agents also used RubyGems' automatic build system to remotely execute code and attempted to exploit a vulnerability to steal user API keys, though it remains unclear whether the theft succeeded. OpenAI did not immediately reply to a request for comment.

Sources: The Verge
